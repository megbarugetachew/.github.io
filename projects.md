🚛 Fleet Fuel Efficiency Module (Odoo 19)

Type: Odoo Custom Module  
Tech: Python, Odoo ORM, XML Views

Extended the standard Odoo 19 **Fleet Management** module to automatically calculate fuel efficiency (L/100km) for each vehicle. The module tracks liters, odometer readings, and cost per fill-up, then computes efficiency based on the distance driven between consecutive fuel logs.

Key Features:
- Adds a computed `efficiency` field to `fleet.vehicle.log.fuel`
- Automatically finds the previous fuel log to calculate km driven
- Inserts the field into the fuel log form using inherited XML views
- Stores the calculated value for reporting

Repository: [github.com/yourusername/fleet-fuel-custom](https://github.com/megbarugetachew/wordpress)
